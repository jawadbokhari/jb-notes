## Concept Mastery Framework

```
I want to understand [concept/topic].

Please explain:
1. Simple Definition: Like I'm a beginner
2. Analogy: Compare to something familiar
3. Components: Break down the key parts
4. Examples: Three real-world applications
5. Common Mistakes: What people get wrong
6. Practice: Give me a problem to solve
7. Resources: Where to learn more

My Background: [Your relevant experience]
Why I Need This: [Your goal]
```

## Study Guide Generator

```
Create a study guide for [topic/chapter/subject]:

Overview: Big picture in 2-3 sentences
Key Concepts (5-7 most important): definition + why it matters, for each
Must-Know Facts: dates/names/formulas with memory tricks
Connections: how concepts relate to each other + visual diagram description
Practice Questions: 5 multiple choice with explanations, 3 short answer, 1 essay question
Common Mistakes: what students often confuse
Quick Review: 10 rapid-fire checkpoints
```
