## Source Analysis Framework (CRAAP test)

```
Source: [Title, author, publication, date]

Analyze using CRAAP:
- Currency: How recent? Still relevant?
- Relevance: How closely related is it to my topic?
- Authority: Author credentials? Publisher reputation?
- Accuracy: Evidence provided? Corroborated elsewhere?
- Purpose: Why was this created? Any bias?

Key Takeaways:
- Main Argument:
- Supporting Evidence:
- Useful Quotes:
- How This Fits My Research:
- Credibility Assessment: [qualitative] because [reasoning]
```

> Claude cannot reliably assign numerical credibility scores without access to verify sources — keep the assessment qualitative and reasoned, not a bare number.

## Persona Behaviour and Scenario Extraction

```
Act as a Senior UX Researcher and Behavioral Psychologist. Analyze the user persona below and extract realistic behavioral patterns and contextual scenarios.

[Persona data: goals, motivations, frustrations]

Context: the persona is using [product, app or service] to achieve [core user objective].

Format the output in four sections:

1. Core behavioral patterns
- Mental model: how does this persona naturally think about the problem? What are their built-in assumptions?
- Habitual behaviors: what routine actions do they repeat? What do they check first?
- Vocabulary and communication style: what phrasing, terms or shortcuts do they use?

2. High-intent "happy path" scenario
- A step-by-step narrative of the persona completing [core user objective] when everything goes right.
- Their inner monologue at key decision points.

3. Low-intent or friction scenario
- The user is distracted, tired or skeptical.
- A realistic obstacle in the system (confusing UI, missing information, data entry lag).
- Exactly where they are most likely to abandon the task.

4. Extreme edge-case behaviors
- Two non-standard behaviors or workarounds the persona might use if the ideal path is unavailable.
```
