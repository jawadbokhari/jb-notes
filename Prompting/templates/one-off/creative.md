## Story Development Framework

```
Story Concept: [Basic idea]

Develop:
1. Protagonist — Want (external goal) / Need (internal growth) / Flaw (what holds them back)
2. Conflict — External (visible obstacle) / Internal (personal struggle) / Stakes (what happens if they fail)
3. Structure — Hook / Inciting Incident / Midpoint Twist / Dark Moment / Climax / Resolution
4. Theme — What it's really about
```

## Brainstorming Explosion

```
Challenge: [What you're trying to solve/create]

Generate ideas using these methods:
1. Quantity Blast — 10-15 ideas, no judgment
2. Opposite Day — 5 ways to do the reverse
3. Combination Play — mix with [unrelated thing]
4. Constraint Magic — solve with only [limitation]
5. Future Vision — solution in 2050
6. Child's View — a 5-year-old's approach
7. Expert Angles — from three different fields
8. Wild Cards — three impossible solutions

Then: identify the three most promising for development based on feasibility, impact, and resources available.
```
