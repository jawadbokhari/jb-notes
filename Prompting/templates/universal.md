## Master Prompt Template
Use as the default skeleton for any non-trivial request.

```
Context: [Background information]
Role: [Who Claude should act as]
Task: [Specific request]
Constraints: [Limitations or requirements]
Format: [How to structure the output]
Examples: [If needed, show desired style]
```

## Problem-Solving Framework

```
Problem Statement: [Clear description]
Current Situation: [Where we are now]
Desired Outcome: [Where we want to be]
Constraints: [Limitations to consider]
Success Metrics: [How we'll measure success]

Claude, analyze this problem and provide:
- Root cause analysis
- Three potential solutions with pros/cons
- Recommended approach with reasoning
- Implementation steps
- Risk mitigation strategies
```

> Verify any critical risk assessments with domain experts — this is a structuring tool, not a substitute for expert judgment.
